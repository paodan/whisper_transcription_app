# Preface
This project is to generate transcriptions for audios, and then it gives a summary according to the transcription. (Though the summary step still needs to be optimized). There is an embedded audio player, where the backward and forward buttons can be handy to do English dictation for English listening practice.

# Install required packages
`pip install -r requirements.txt`

# How to use this package
* Run the package in a terminal with `python app.py`
* Open the browser and go to the following link `http://localhost:5000`
* Upload an audio file and click Transcribe.
